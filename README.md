# PrintBot — автоматизація прийому замовлень для точок друку

**PrintBot** — це готовий сервіс для копіцентрів, фотосалонів і типографій, який замінює хаос у Viber/Telegram на структуровану чергу замовлень з автоматичними сповіщеннями.

---

## Як це виглядає для вашого клієнта

Клієнт пише у ваш Telegram-бот або відкриває веб-сторінку по QR-коду:

1. Надсилає файл (PDF, Word, фото)
2. Вибирає параметри: кольоровість, односторонній/двосторонній, формат, кількість копій
3. Отримує підтвердження замовлення з номером

Коли замовлення готове — клієнт автоматично отримує повідомлення в Telegram. Жодних дзвінків, жодного «нагадайте мені номер».

---

## Як це виглядає для оператора

Оператор має два способи роботи із замовленнями:

### Панель у Telegram-боті
Команда `/operator` прямо в боті:
- Черга замовлень з типом файлу, кількістю сторінок і часом надходження
- Файл одразу приходить у чат, готовий до друку
- Натискає «Надруковано» — клієнт отримує повідомлення

### Веб-панель оператора
Окремий дашборд за адресою `printbot-operator.duckdns.org`:
- Повна черга замовлень у реальному часі
- Управління статусами, фільтрація, перегляд файлів
- Доступ з будь-якого пристрою через браузер — без встановлення додатків
- Вхід за API-ключем точки

Не потрібен окремий комп'ютер, не потрібна нова програма.

---

## Два канали прийому замовлень

### Telegram-бот
Клієнт надсилає файл у бот — бот задає питання і оформлює замовлення. Підходить для постійних клієнтів.

### Веб-форма
Клієнт сканує QR-код на стійці → відкриває сторінку в браузері → завантажує файл без реєстрації. Підходить для нових клієнтів і тих, у кого немає Telegram.

Обидва канали надходять в одну чергу до оператора.

## Персональне налаштування

Сервіс адаптується під вашу точку без розробки:

**Прайс-лист** — задаєте свої ціни на чорно-білий друк, кольоровий, фото різних форматів. Калькулятор автоматично рахує вартість при оформленні замовлення.

**Назва і бот** — бот реєструється на ваше ім'я, клієнти бачать назву вашої точки. Реєстрацію бота бере на себе наш менеджер.

**Параметри друку** — налаштовуються формати паперу, типи паперу, опції (ламінація, брошурування) відповідно до вашого обладнання.

**Пароль оператора** — задаєте свій, щоб доступ до панелі мали тільки ваші співробітники.

**Мова інтерфейсу** — українська або російська.

## Питання і відповіді

**Чи потрібен інтернет в точці?**
Так, для отримання файлів від клієнтів потрібне з'єднання. Якщо інтернет нестабільний — розглянемо локальне розгортання.

**Чи можна підключити кількох операторів?**
Так, кілька людей можуть одночасно користуватись панеллю оператора в одному боті та веб-дашборді.

**Чи зберігаються файли клієнтів?**
Файли зберігаються на захищеному сервері. Ви можете налаштувати автоматичне видалення через заданий час.

**Чи можна інтегрувати з касою або CRM?**
На тарифі Бізнес доступний webhook — передача даних замовлень у будь-яку зовнішню систему (Google Sheets, CRM, n8n-сценарії).
